# نقل المستندات الاثني عشر إلى cmms — 2026-11-07

طلب المستخدم تطبيق نفس إجراء COPYCMMS2 على القاعدة الأصلية، مع التنفيذ اليدوي والانتقال خطوة بخطوة. لا تغيير لواجهة أو صلاحية أو كاتب مالي أو مخزون أو قالب PDF في هذه المرحلة.

## ما ثبت

- نفذ المستخدم إنشاء جدول التصحيحات على cmms. أكد فحصه وجود الحزم الاثنتي عشرة المؤرشفة ومعرفاتها وبصمات snapshot.
- قرأ `collect-cmms.ts` مصادر cmms مستقلة باستخدام اتصالها السابق الذي زوده المستخدم، وSELECT فقط وTLS موثق، دون استيراد عميل DB التطبيق أو مجدولاته. متغير الاتصال استُعمل للعملية المؤقتة فقط، ولم يتغير .env.
- تطابقت المعرفات وبصمات snapshot وبصمات المصادر المالية والاعتمادات ولقطات المندوب وملفاته وصور التوقيعات وجميع تفاصيل النموذج المعتمد للحزم الاثنتي عشرة مع مصادر التجربة. لذلك نسخت ملفات PDF المعتمدة نفسها حرفيًا؛ لم تعاد صياغتها.
- جُهزت ملفات إدخال خاصة بـcmms وحزمة `output/pdf/legacy-dpb-cmms-v2-ready.zip` خارج Git. تحققت بصمات24PDF وأوامر SQL الاثني عشر، وراجعت صفحات المعاينة13التي تمثل نفس البايتات.

## المشغّل اليدوي

- `import-manual.cjs --check`: محلي دون اتصال.
- `--read-check`: يتحقق من الهوية والمصادر المالية والأرشيف بقراءات فقط. أثبت الفحص الحقيقي12مصدرًا مطابقًا و0سجل مثبت و0كتابة.
- `--apply`: لا ينفذه الوكيل. يضيف12سجلًا إلى جدول التصحيحات وحده؛ يعيد مقارنة snapshot والمصادر المالية لكل الحزم قبل أول كتابة، ثم داخل معاملة كل مستند. يتحقق من بايتات كل سجل قبل commit، ويتوقف عند اختلاف أو0rows أو خطأ. يقبل إعادة التشغيل مع تجاوز السجلات المطابقة، ويرفض الموجودة المختلفة. لا UPDATE/DELETE/DDL.
- يقبل رابط اتصال الأصل من إعداد محلي مطابق أو `CMMS_PDF_DATABASE_URL` للعملية فقط؛ وإلا يطلب الرابط في الطرفية مع إخفاء الإدخال. يثبت اسم القاعدة والخادم والحساب المقروء ببصمة، ولا يغير .env الخاص بالتجربة أو يخزن كلمة السر. بصمات المصدر متطابقة مع دالة قارئ التطبيق.
- نجحت12حالة محاكاة لهوية القاعدة/الاتصال وتغير المصدر قبل الكتابة وداخل المعاملة والتكرار ورفض نسخة قديمة والتوقف والتراجع والتحقق.

## المتبقي

تنفيذ المستخدم `--apply` على الأصل، ثم التحقق12/12/12/12 من القاعدة وتنزيل مستند من الموقع الرئيسي بالكود النهائي. لم ينفذ الوكيل إدخالًا على cmms أو نشرًا أو تعديلًا ماليًا. اكتمل الإدخال اليدوي على COPYCMMS2 سابقًا واختبر تنزيل009من المركز محليًا؛ طابقت بايتاته النسخة المصححة.
