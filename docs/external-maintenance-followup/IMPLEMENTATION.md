## النطاق والسلوك

- تبقى مرحلة تجهيز المستودع واستلام المندوب ثم خروج الحراسة وإنشاء PR بعنوان المستودع كما نُفذت سابقًا. لا تغيير لنموذج العهدة أو دورة اعتماد الحسابات والإدارة أو إجراءات الدخول والاستلام والتسليم وإعادة التركيب.
- حفظ سعر الصيانة الخارجية يلزم اسم الورشة وهاتفها وتاريخ العودة المتوقع DATE من التقويم. رابط موقع الورشة http/https والملاحظات اختياريان. لا يُفرض قيد تاريخ مستقبلي على الإدخالات التاريخية، ولا تُخمن بيانات ورشة قديمة.
- تبويب «متابعة الصيانة الخارجية» داخل طلبات الشراء يعرض الأصل بعد اكتمال اعتماد الصنف ودفعة التسعير وPB/DPB الفعلية، وليس حالة رأس PR وحدها. البطاقة المختصرة تعرض عنوان المستودع وصورة الأصل والمندوب وموعد العودة وحالة الوقت؛ التفاصيل داخل نافذة قابلة للإغلاق، والصور لها تكبير وإغلاق.
- الأيام تُحسب بحسب تقويم الرياض وتاريخ العودة الشامل ليومه. gateEntryApprovedAt يوقف احتساب التأخير؛ تبقى البطاقة «بانتظار استلام المستودع» حتى warehouseReceivedAt. عند الاستلام تختفي من الجارية وتظهر داخل مجموعة «الصيانة الخارجية المستلمة» في «الكل». لا يُغلق البلاغ ولا تُنفذ إعادة تركيب تلقائية.
- «الكل» للمندوب/مسئول المناديب يعرض أرشيف أصوله الخارجية المستلمة فقط؛ لا يُفتح له عرض PR العام. بقية الأدوار تحتفظ بقائمة الشراء العادية إلى جانب مجموعة المستلم، دون حذف صفوفها أو تغيير عداداتها. التفاصيل تعرض المرحلة الفعلية اللاحقة ولو بدأت إعادة التركيب أو أُغلق البلاغ.

- الخدمة withExternalWorkshopPricing تغلف الكتابة الحالية فقط عند وجود مصدر خارجي متحقق منه. المستخدم والطلب والبند وjob ومصدر C يُقرأون حديثًا تحت الأقفال، ويحفظ السعر والورشة والتدقيق داخل tx واحدة. إخفاق السعر أو حفظ الورشة أو التدقيق يرجعها كلها.

- إثراء الورشة في تفاصيل PR/الحزمة وقوائم التسعير وmyItems يتم بعد التصفية الحالية وبـcontext batch محدود500. لا ترفق بيانات الورشة إذا لم تتطابق هوية المندوب والبند الوحيد والطلب والبلاغ وبند C. الأصناف العادية لا تُرسل لها حقول ورشة ولا يتغير كاتب تسعيرها.
