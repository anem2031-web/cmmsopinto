# استلام المندوب للأصل قبل الحراسة — 2026-11-04

## النطاق المنفذ

- عنوان طلب شراء إلزامي مستقل عن اسم الأصل (حتى 300 حرف)، ثم تجهيز الأصل واختيار المندوب وإصدار وثيقة الخروج وطباعتها. تبقى المهمة في `waiting_delegate_receipt` قبل الحراسة.
- تبويب «الصيانة الخارجية» للمندوب الفعلي النشط يعرض مهامه المسندة إليه قبل PR فقط: العنوان، الأصل، رقم البلاغ ووصف عطل البند، حالة الأصل، الملاحظات، رقم الوثيقة وصورة الأصل المسجلة مع التكبير والإغلاق.
- قبول الاستلام الفعلي ينقل المهمة للحراسة؛ الرفض بسبب إلزامي يعيد نفس السجل والوثيقة للمستودع. إعادة التجهيز تسمح بتغيير المندوب وتزيد نسخة التجهيز وتلغي الإثبات السابق، مع حفظ القرار والسبب السابقين في التدقيق والتاريخ.
- اعتماد الحراسة يتحقق من قبول المندوب الحالي للتجهيز الحالي قبل حجز رقم شراء. اسم بند PR هو العنوان المحفوظ دون بادئة «صيانة خارجية:»؛ قالب العهدة القائم يقرأ الاسم نفسه. دورة التسعير والاعتمادات والاستلام اللاحقة لم تُعد تصميمها.

## الضبط والصلاحيات

- المعاملات وأقفال المصدر والمهمة ونسخة التجهيز تمنع القرار المكرر وقبول المندوب القديم وإنشاء أكثر من PR من اعتماد الخروج المتكرر.
- القائمة والإجراء والصورة تعيد فحص الحساب الفعلي النشط والإسناد والبلاغ والبند والمسار C واعتماد العمل. ليس التبويب إذنًا عامًا لصفحة البلاغ أو الصور الأخرى. طلب الصورة بعد إعادة التعيين لا يُتاح للمندوب السابق.
- إخطار الحراسة بعد قبول الاستلام فقط؛ الرفض يُخطر المستودع بالسبب. لا PR أثناء تجهيز المستودع أو قبول المندوب.

## SQL يدوي قبل تشغيل النسخة

1. افحص الأعمدة بأول SELECT في `01_delegate_receipt_copycmms2.sql`.
2. قارن تعريف status الحالي؛ التعديل يحافظ على ترتيب القيم العشر السابقة ويضيف `waiting_delegate_receipt` في النهاية.
3. نفذ عبارات ALTER السبع منفصلة. لا تنفذ ADD لعمود موجود. توجد ستة أعمدة جديدة فقط بجانب توسيع status، ولا فهرس إضافي أو Backfill.
4. أعد SELECT للتحقق من سبعة صفوف: status والأعمدة الستة.
5. جرّب الدورة على التجربة. ملف `02_delegate_receipt_cmms.sql` نظير مؤهل لـcmms، وليس تنفيذًا تلقائيًا عليها.

الـDDL لا تحميه START TRANSACTION/ROLLBACK. لم ينفذ الوكيل اتصال قاعدة أو SQL أو تعديل بيئة أو نشرًا.

## السجلات السابقة

ما تجاوز خروج الحراسة يبقى بتاريخه وطلب شرائه كما هو. القديم المنتظر للخروج بلا عنوان أو إثبات صالح يظهر للمستودع لإعادة التجهيز صراحةً ثم انتظار المندوب؛ يبقى نفس السجل والوثيقة، ولا يُختلق استلام قديم.
