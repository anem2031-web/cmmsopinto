# مطابقة نموذج DPB المعتمد — 2026-11-01

طلب المستخدم استخدام النموذج المرفق `C:/Users/mh/Downloads/PB-2026-150006-5-معتمدة-حسابات.pdf` للوثيقة المعتمدة، مع الحفاظ على تجميع الحزمة ونسخة المندوب ودورة الاعتماد الحالية.

## التنفيذ

- فرع DPB المعتمد في `server/services/export/exportService.ts` يستخدم ترتيب نموذج PB وتنسيقه: بيانات الرأس، جدول الأصناف بسبعة أعمدة، إقرار المستودع، توقيعات مقدم الطلب والمراجع والمندوب والحسابات، ثم الشؤون المالية ورئيس الحسابات والرئيس التنفيذي وحقول سند الصرف.
- أزيل الملحق المنفصل المكرر للاعتمادين. الحسابات والإدارة تستخدمان هويتي المعتمدين وتوقيعيهما المحفوظين والتاريخ المثبت؛ لا نسخ لأسماء أو توقيعات المرفق المرجعي. خانة رئيس الحسابات اليدوية تبقى فارغة كما في النموذج.
- تبقى الحزمة برقم DPB وأرقام طلباتها الأصلية وترتيب أصنافها؛ عدد الصفحات يتبع محتواها. لا نسخ لقيم المرفق المرجعي أو بياناته. تجمع التوقيعات المتكررة للشخص نفسه مع الاحتفاظ بمراجع طلباته عند تعدد المصادر.
- أثر الرفض محفوظ: الصف غير المعتمد وسببه والإجمالي الأصلي والمقبول لا تحذف. عند قبول جميع الصفوف يظهر الإجمالي المعتاد دون تكرار. النطاقات المالية التاريخية المستقلة تبقى منفصلة ولا تجمع أرصدتها.
- لا تغيير لملف المندوب المجمد أو لقالب PB القائم أو شرط ظهور الوثيقة أو الصلاحيات أو مسارات الاعتماد والتمويل والشراء والمخزون.

## التحقق

- `node tools/unified-dpb-approval/run.mjs`: نجحت368 حالة في14 ملفًا؛ بينها17 حالة لقالب المستند المعتمد، تشمل نسخة المندوب والرفض الجزئي وعدم تعديل اللقطة.
- بناء الإنتاج ناجح. `npm run check` ما زال غير ناجح بأخطاء عامة سابقة خارج ملفات هذا التعديل؛ لم يظهر تشخيص في `exportService.ts` أو اختبار القالب أو مولد المعاينة.
- `node tools/pricing-bundle-approved-document/reference-preview.mjs`: معاينة بثلاثة أصناف وثلاثة PR، إجمالي600 ورصيد عهد265، في صفحة A4 واحدة. الملف: `output/pdf/DPB-approved-form-sample.pdf`.
- `node tools/pricing-bundle-approved-document/reference-preview.mjs --stress`:20صنفًا و20طلبًا في صفحتين A4. روجعت الصفحات الثلاث المعروضة في التجربتين بصريًا بعد التصحيح الأخير؛ لا قص أو تداخل، وينتقل عنوان القسم المالي مع محتواه.
- المولد يستخرج دالة التصدير الفعلية ومساعداتها النقية ويمنع أي قراءة قاعدة أو طلب خارجي. جميع أسماء المعاينة وتوقيعاتها وهمية وموسومة بأنها تجريبية، وليست مستندًا صادرًا فعليًا.

## حدود التسليم

لم يحصل اتصال قاعدة بيانات أو SQL أو تغيير `.env` أو نشر أو قرار اعتماد مالي حي. يلزم نشر النسخة ثم اختبار المستخدم تنزيل وطباعة وثيقة فعلية من مركز المستندات ومقارنة بيانات المعتمدين المحفوظة ونسخة المندوب. لا يلزم SQL لهذه المطابقة.
